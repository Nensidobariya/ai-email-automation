# AI Email Automation Tool

> Automatically generates professional business emails 
> using Google Gemini API and Python

---

## Project Overview

This tool takes simple user inputs and generates 
complete, ready-to-send professional emails using 
Google's Gemini AI model — saving hours of manual 
email writing time.

---

## Features

- Generates complete professional emails instantly
- Supports multiple tones (formal/friendly/urgent)
- Customizable purpose, recipient and details
- Powered by Google Gemini AI API
- Simple command-line interface

---

## Tech Stack

| Tool | Purpose |
|---|---|
| Python 3.12 | Core programming language |
| Google Gemini API | AI text generation |
| google-genai library | API integration |

## How to Run

### 1. Install dependency
```bash
pip install google-genai
```

### 2. Add your API key
```python
API_KEY = "your-gemini-api-key-here"
```
Get free API key at: https://aistudio.google.com

### 3. Run the tool
```bash
python email_automation.py
```
